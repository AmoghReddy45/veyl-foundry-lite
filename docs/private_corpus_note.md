# Public and private material

This repository contains one intentionally public example, its visible fixtures,
its passing implementation, the Lite runner, and public-facing documentation.
The [research guide](public_evidence.md) links to separately published studies.

The managed platform's implementation, private evaluation collections, grading
material, internal experiments, operational records, and customer information
are not distributed here. A link to a public study does not make its underlying
private development workspace part of this repository.

The published [data boundary](https://veyl.work/security) keeps customer-derived
evaluation scenarios isolated to the organization. Publication, resale,
cross-customer use, or training requires separate written permission. The
included billing example uses public sample data and makes no claim to represent
a customer's environment.

For questions about an engagement's data handling, contact
[amogh@veyl.work](mailto:amogh@veyl.work).
